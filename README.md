# 键政派系测试 · 观点档案室

一个轻量、无依赖的中文互联网政治坐标趣味测试：12 道 SCENE 场景题 + 9 大派系画像，生成可直接分享到小红书的竖版结果海报。

> 纯前端实现，所有答案与结果仅在本地处理，不上传任何数据。

## 功能

- **12 道 SCENE 场景题**  
  把抽象的政治坐标拆成日常选择，每题只选一个最贴近直觉的选项。

- **四轴量化模型**  
  个人自由 · 社会公平 · 制度信任 · 情绪参与，用进度条直观呈现得分。

- **9 大派系画像**  
  自由派 / 建制派 / 左派 / 改良派 / 加速派 / 皇汉 / 神友·抽象派 / 岁静派 / 乐子人。

- **原生 Canvas 海报**  
  点击"生成分享海报"即可生成竖版图片，适配小红书竖图分享。

- **程序化 SVG 徽章**  
  每个派系都有对应的矢量图标，跟随主题色自动变化。

- **零依赖 / 零上传**  
  HTML + CSS + JS 单页应用，无构建步骤，无服务端，无数据收集。

## 本地运行

```bash
# 1. 克隆仓库
git clone <repo-url>
cd 小红书小工具

# 2. 启动本地服务器
python -m http.server 8000
# 或
npx serve .
# 或 VS Code Live Server

# 3. 浏览器打开 http://localhost:8000
```

> 注意：因为浏览器安全策略，直接双击 `index.html` 打开可能导致本地资源加载问题，建议通过本地服务器访问。

## 设计思路（可写进简历的亮点）

1. **从"立场站队"到"坐标切片"**  
   不问你支不支持某个口号，而是把你放进 12 个具体场景里，通过你选择相信什么、先看见什么，拼出你的坐标。

2. **规则驱动的画像匹配**  
   没有调用任何 AI / LLM，画像文案、坐标分、关键词全部内聚在 `profiles` 数据中，保证离线可运行、结果可预期。

3. **原生 Canvas 海报渲染**  
   海报内的标题、坐标轴、剖析文字、关键词标签全部用 Canvas 2D API 绘制，不依赖任何图表库，输出图片可直接保存发小红书。

4. **隐私优先**  
   所有计算在浏览器完成，无后端、无埋点、无上传。
